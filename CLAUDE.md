# CWL

Next.js 14 (App Router) site for the Catholic Women's League Aotearoa New Zealand.
Source lives in `src/` — `app/` for routes, `components/` for UI (CSS Modules alongside), `lib/` for data.

## Workflow

- Don't run type checks or builds (`npm run build`, `tsc`) after making changes. The user verifies in their own dev server.
